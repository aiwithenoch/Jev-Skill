# Security Policy

## Supported versions

The `main` branch and the latest tagged release receive security fixes.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Report it
privately through the contact options on <https://aiwithenoch.com> and include
the affected file, reproduction steps, impact, and a suggested mitigation if
known.

Never include API keys, customer data, private golden sets, or other secrets
in an issue, pull request, benchmark, or test fixture.
